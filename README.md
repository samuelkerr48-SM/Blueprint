# Blueprint – instructional coaching

Blueprint helps instructional coaches observe a lesson, debrief it with the teacher and agree one rehearsed next step, aligned to the VTLM 2.0.

**Open it:** visit this site's GitHub Pages address, then choose **Install Blueprint** (the install icon at the right of Chrome or Edge's address bar) to add it as an app with its own window and Start menu icon. On an iPad: Share › Add to Home Screen.

All coaching notes stay on the coach's own device and in their own SharePoint folders. This site only delivers the tool; it collects no data.

**Updating:** replace `index.html` (and `sw.js`, which carries the version number) with the new build. Installed copies pick up the new version the next time they're opened online.
